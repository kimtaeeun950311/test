# Ketmong - 반려견 라이프스타일 앱
React Native · Expo · TypeScript 기반으로 개발하는 반려견 라이프스타일 서비스입니다.

---

## 소개
Ketmong은 반려견과 보호자의 일상을 더 즐겁고 편리하게 만드는 것을 목표로 합니다.  
산책 미션, 보상 시스템, 반려견 프로필, 활동 기록 등 다양한 기능을 제공합니다.

---

## 주요 기능

### 1. 산책 루렛 (Dog Walking Roulette)
- 매 산책마다 랜덤 미션을 제공하여 산책 루틴을 더 재밌게 만듭니다.

### 2. Bone 보상 시스템
- 하루 3회 제공되는 Bone을 모아 다양한 기능을 해금할 수 있습니다.

### 3. 반려견 프로필
- 반려견의 정보, 성향, 활동량 기반으로 맞춤형 경험을 제공합니다.

### 4. 활동 기록 (Activity Tracking)
- 산책 횟수, 거리, 활동 데이터를 기록하고 시각화합니다.

### 5. AI 헬스 기능 (v2.0 예정)
- 반려견 사진 기반 건강 체크
- 증상 분석 및 병원 추천
